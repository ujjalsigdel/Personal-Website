## 🚀 Running Locally

Clone the repository

```bash
git clone https://github.com/ujjalsigdel/Personal-Website.git
```

Switch to this branch

```bash
git checkout v1.0-original
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
